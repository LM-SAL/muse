``read_response``, ``read_responses`` and ``save_response`` accept only the layout ``save_response`` writes: a ``line`` or ``channel`` dimension, ``line_wavelength``, and units on ``logT``, ``doppler_velocity`` and the wavelengths. ``migrate_response`` is removed: convert an older file once with muse 0.3, reading it with ``read_response``, which adds what the layout needs, and writing it with ``save_response``.
