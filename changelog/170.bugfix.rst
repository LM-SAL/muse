`muse.synthesis.create_simple_vdem` now conserves emission measure: each temperature bin holds the column n_e n_H dl, in 1e27 cm^-5, of the part of each cell's log T span inside it, so the VDEM no longer changes with the simulation's resolution, and plasma outside the temperature or velocity grid adds nothing and is reported in an info message. VDEMs built before this change, including the hosted example VDEM, differ, and the synthesis tutorial now builds its VDEM from n_e n_H instead of n_H squared.
