``wavelength_to_doppler`` adds the Doppler shift of each detector pixel as ``detector_doppler_velocity``, in place of ``doppler_velocity``, which is the velocity axis of a VDEM and of a response. ``calculate_moments`` reads the new name by default, and ``doppler_to_wavelength`` takes ``doppler_name``, by default the same. Code that reads ``spectrum.doppler_velocity`` after ``wavelength_to_doppler`` has to read ``spectrum.detector_doppler_velocity``.
