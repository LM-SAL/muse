Added ``generate_sg_responses``, ``generate_sg_continuum_responses`` and ``generate_ci_responses``, which write the response products of a set of effective-area files, one file each, under ``<output>/<abundance>/``, using fiasco by default; imager responses are in DN. ``skip_existing=True`` finishes an interrupted run, keeping the products already written; one made with other settings raises an error. An SG waveband spans the new ``DEFAULTS_MUSE`` field ``waveband_half_width_SG`` (over the spectral order) on each side of the channel, with the line responses sampled at the new ``wavelength_step_SG``.
