Renamed arguments, old → new. ``match_fov``: ``dx_pix``, ``dy_pix`` → ``pixel_width``, ``pixel_height``; ``nslits``, ``nraster`` → ``number_of_slits``, ``steps_per_raster``; ``x_extent`` → ``extent``, with ``"extend"`` for ``"tile"``; ``mode`` → ``pad_mode``; ``sub_interpolation`` → ``oversampling``. ``reshape_x_to_slit_step``: ``nslits``, ``nraster`` → ``number_of_slits``, ``steps_per_raster``, and ``reshape_slit_step_to_x`` takes the dataset alone. ``map_response_to_sg_detector``: ``slit_spacing`` → ``pixels_between_slits``, ``detector_pixels`` → ``detector_x_pixels``. ``calculate_moments``: ``integration_name`` → ``variable_name``, ``vmax`` → ``maximum_doppler_velocity``, ``vmask`` → ``peak_half_width``, which now also works alone. ``align_response_and_vdem``: ``coord_methods`` → ``coordinate_methods``. ``create_simple_vdem``: ``velocity_axis``, ``log_temperature_axis`` → ``velocity_grid``, ``logT_grid``. ``read_response``: ``slit`` → ``number_of_slits``, an integer such as ``vdem.sizes["slit"]``. The first argument of ``vdem_synthesis`` is ``vdem`` (was ``raster``), and that of ``wavelength_to_doppler`` and ``doppler_to_wavelength`` is ``data`` (was ``response``). The attributes that record these arguments on a result take the new names too.
