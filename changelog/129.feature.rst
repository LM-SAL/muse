Added ``generate_sg_responses``, ``generate_sg_continuum_responses`` and ``generate_ci_responses``, which write the response products of a set of effective-area files: one set of products per effective-area file, abundance and plasma point, each product in a file of its own. Every product is named before any work is done, so a name that would be used twice, or a product that already exists, stops the call at its start; ``skip_existing=True`` finishes a call that stopped halfway.
