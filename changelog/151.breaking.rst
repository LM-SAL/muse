The transitions of a line list lie along ``transition`` in place of ``trans_index``. Files written by muse 0.3, with ``trans_index``, the former version and provenance attributes or the former pair of ``step_size`` attributes, are no longer read under those names: convert them once, as the tutorial data has been. A line list or a cache along ``trans_index``, and a ``step_size`` without its unit, are refused with a message that says so; so is a line list without a ``transition`` dimension, which was given one of length one. The tutorial data of the muse-data release v1 is replaced by its converted copy, the same data under the current names, so muse 0.3 no longer passes the hash check of those files.
