The transitions of a line list lie along ``transition`` in place of ``trans_index``. Files written by muse 0.3, with ``trans_index``, the former version and provenance attributes or the former pair of ``step_size`` attributes, are no longer read under those names: convert them once, as the tutorial data has been. The tutorial data of the muse-data release v1 is replaced by its converted copy, the same data under the current names, so muse 0.3 no longer passes the hash check of those files.
