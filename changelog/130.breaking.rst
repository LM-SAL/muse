``DEFAULTS_MUSE.spectral_slit_separation_SG`` holds one value per SG channel, as an `xarray.DataArray` along ``channel``, in place of one value for all: select a channel with ``.sel(channel=171)``. ``map_response_to_sg_detector`` takes the value of its channel, and the names of the SG detector products state it. The three values equal the former single value, so the responses and the product names do not change.
