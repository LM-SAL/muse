Added ``generate_sg_responses``, ``generate_sg_continuum_responses`` and ``generate_ci_responses``, which write the response products of a set of effective-area files as zarr stores: one set per file, abundance and plasma point. Every product is named before any work is done, so a name that would be used twice, or a product that is already there, stops the call at its start; ``skip_existing=True`` finishes a call that stopped halfway.
